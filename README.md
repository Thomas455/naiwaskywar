# 奶娃战机 · Naiwa Sky War

一个**纯静态**的网页竖版弹幕射击小游戏：拖动奶娃战机躲子弹、打敌机、捡道具、刷分数。
手机和电脑都能玩，全部素材本地存放，直接丢到 GitHub Pages 就能跑。

## 玩法

- **拖动即玩**：手机用手指在屏幕上拖动，电脑直接移动鼠标（也可以按住拖）。
  战机跟手移动，不用按任何开火键。
- **自动射击**：奶娃会持续朝正前方开火，你要做的就是走位。
- **难度递增**：每 20 秒升一级，敌人更多、更快、更耐打，弹速和射速一起涨；
  每 60 秒会来一只 **Boss（奶鸡王）**。
- **连击**：2.5 秒内连续击落敌机可叠加连击倍率，最高 **x5**。

### 计分

击落敌机（100 ~ 5000 分 × 连击倍率）、**持续存活每秒 +10**、拾取道具 +50、
升级奖励 +500 × 等级，Boss 击破额外加成。

## 本地运行

由于是纯静态站点，直接双击 `index.html` 就能玩。想用本地服务器：

```bash
node ../tools/serve.js 8765
# 打开 http://127.0.0.1:8765/
```

## 部署到 GitHub Pages

1. 把本仓库推到 GitHub。
2. 仓库 **Settings → Pages → Build and deployment**：
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 **`/docs`**
3. 保存后等一分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

整站没有构建步骤、没有外部 CDN、没有后端，`docs/` 目录本身就是完整产物。
（`docs/.nojekyll` 用来避免 Jekyll 处理，路径大小写敏感问题也随之规避。）

## 目录结构

```
docs/                  ← 部署目录，即站点根目录
├── index.html
├── css/style.css
├── js/
│   ├── core.js        ← 纯逻辑模型（计分 / 难度 / 刷怪 / 碰撞），可在 Node 里单独测试
│   ├── assets.js      ← 素材加载
│   ├── audio.js       ← WebAudio 现场合成音效（无音频文件）
│   ├── render.js      ← Canvas 渲染
│   ├── input.js       ← 拖动 / 鼠标 / 键盘输入
│   ├── ui.js          ← 菜单、HUD、暂停、结算
│   └── main.js        ← 启动与主循环
├── assets/            ← 由「资源」文件夹加工出来的游戏素材
└── .nojekyll
```

## 素材说明

原始素材放在仓库的 `资源/` 文件夹，全部是**不透明**图片（没有 alpha 通道）。
`_tools/` 里的 Python 脚本负责把它们加工成游戏素材：

- `build_assets.py`：按「与背景色的全局容差 + 局部梯度」做连通域泛洪抠图，
  第二遍再吃掉与底色平滑相连的软阴影，最后羽化边缘并裁到内容边界。
- `bake_ship.py`：把奶娃本体和程序绘制的天使羽翼、侧舷机炮、推进器合成为玩家战机。
- `build_game_assets.py`：一次性产出 `docs/assets/` 下的全部素材（含 Boss 金冠、
  天使特效的径向遮罩、菜单背景等）。
- `build_space_bg.py`：从「天使降临.jpg」上部的深空裁出游戏内星云背景。

重新生成素材：

```bash
python _tools/build_game_assets.py
python _tools/build_space_bg.py
```

## 测试

核心玩法逻辑与 DOM 无关，可以直接在 Node 里跑：

```bash
node tests/core.test.js
```

覆盖：难度曲线单调性、自动开火、拖拽边界、各类计分、连击窗口、四种道具效果、
受伤与无敌、结算与重开、暂停、6 分钟长局稳定性、随机种子可复现等。

## 调试参数

在 URL 上追加查询参数可以进入调试模式（正常游玩不会触发）：

| 参数 | 作用 |
| --- | --- |
| `?auto=1` | 自动驾驶演示模式 |
| `?auto=2` | 自动开局但不动（用来复现阵亡结算） |
| `?warp=60` | 开局先快进 60 秒 |
| `?stage=430x860` | 把舞台锁定成指定像素尺寸（截图用） |
| `?show=help` | 直接打开某个界面 |
| `?pauseafter=1` | 快进结束后立刻暂停 |
| `?metrics=1` | 把关键元素实测尺寸打印到页面上 |

## 浏览器支持

Chrome / Edge / Firefox / Safari 的现代版本（用到 Canvas 2D、Pointer Events、
WebAudio、`localStorage`）。不支持时会在控制台静默降级，不影响游玩。
