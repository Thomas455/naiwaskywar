# 奶娃战机 · Naiwa Sky War

[点击游玩](https://thomas455.github.io/naiwaskywar/)

一个**纯静态**的网页竖版弹幕射击小游戏：拖动奶娃战机躲子弹、打敌机、捡道具、刷分数。
手机和电脑都能玩

## 玩法

- **拖动即玩**：手机用手指在屏幕上拖动，电脑直接移动鼠标（也可以按住拖）。
  战机跟手移动，不用按任何开火键。
- **自动射击**：奶娃会持续朝正前方开火，你要做的就是走位。
- **难度递增**：每 20 秒升一级，敌人更多、更快、更耐打，弹速和射速一起涨，
  难度最高 **100 级**；每 60 秒会来一只 **Boss（奶鸡王）**。
- **连击**：2.5 秒内连续击落敌机可叠加连击倍率，最高 **x5**。

### 多人联机（最多 4 人）

主菜单选「多人联机」，可以**创建房间**当房主，或者**加入房间**。
联机需要几台设备在**同一局域网**（或都能正常访问公网）下。

- 房间号是 **4 位数字**（例如 `8300`），念给朋友听或者直接发二维码都行。
  万一在公共信令服务器上连续撞号，会自动升级成 **5 位字母+数字**（例如 `A7K2M`）。
- 加入方式有三种：**手动输入房间号**、点「扫码加入」用摄像头扫房主的二维码、
  或者**用手机自带的相机 / 微信扫一扫**直接扫（链接里带着房间号，打开就自动加入）。
  网页内扫码自带解码器，不依赖浏览器有没有 `BarcodeDetector`。
- 局内每位玩家头顶有 **P1~P4** 标记，**自己的战机**会额外套一圈闪烁光环和「你」字提示，
  而且永远画在最上层，人挤在一起也不会被队友挡住。
- **人越多越难**：每多一名玩家，敌机血量 +50%、出怪更快、敌机更快，Boss 也更厚。
- **阵亡后 120 秒复活**，代价是火力降一级。等待期间自动进入**观战**：
  画面会高亮一名活着的队友并标注「观战中」，顶部观战条显示你正在看谁、还有多久复活；
  点屏幕任意位置或点「切换视角」就能在活着的队友之间轮换。
  队友全倒下就没人可看了，只能等自己复活。
- **全员同时倒下才算团灭**。中途加入的玩家会直接并入当前对局。
- **暂停由房主控制**：房主按暂停所有人一起停；客人不能暂停，但可以随时点 🚪 离开房间。

联机走 **WebRTC 点对点**（PeerJS + 公共信令服务器 `0.peerjs.com`），
主机权威：房主跑真正的模拟，客人只上报自己的位置、收世界快照并本地预测自己的战机。
**客人会采用房主的战场尺寸**（等比缩放 + 居中留黑边），这样双方看到的战场完全一致，
队友的位置才不会错位。

### 计分

击落敌机（100 ~ 5000 分 × 连击倍率）、**持续存活每秒 +10**、拾取道具 +50、
升级奖励 +500 × 等级，Boss 击破额外加成。

## 本地运行

由于是纯静态站点，直接双击 `index.html` 就能玩。想用本地服务器：

```bash
node ../tools/serve.js 8765
# 打开 http://127.0.0.1:8765/
```
## 目录结构

```
├── index.html           ← 源码入口（改这个，`docs/` 是发布用的副本）
├── css/style.css
├── js/
│   ├── core.js          ← 纯逻辑模型（计分 / 难度 / 刷怪 / 碰撞 / 多人），可在 Node 里单独测试
│   ├── net.js           ← 联机层：PeerJS 封装 + 世界快照编解码
│   ├── assets.js        ← 素材加载
│   ├── audio.js         ← WebAudio 现场合成音效（无音频文件）
│   ├── render.js        ← Canvas 渲染（含 P1~P4 标记、护盾破裂冲击波）
│   ├── input.js         ← 拖动 / 鼠标 / 键盘输入
│   ├── ui.js            ← 菜单、HUD、暂停、结算、联机大厅
│   └── main.js          ← 启动、主循环、状态机、联机编排
├── vendor/
│   ├── peerjs.min.js    ← WebRTC 封装（已本地化，不走 CDN）
│   └── qrcode.js        ← 二维码生成（已本地化）
├── assets/              ← 由「资源」文件夹加工出来的游戏素材
├── docs/                ← GitHub Pages 实际发布的副本
└── .nojekyll
```

## 浏览器支持

Chrome / Edge / Firefox / Safari 的现代版本（用到 Canvas 2D、Pointer Events、
WebAudio、`localStorage`）。单人游玩不支持时会在控制台静默降级，不影响游玩。

**联机**需要浏览器支持 WebRTC（上面这些现代版本都支持）。
网页内「扫码加入」依赖 `BarcodeDetector`（Chrome / Edge / Android 上有），
不支持时会提示改用手机相机扫码或手动输入房间号 —— 这两条路在任何浏览器上都能用。

> 注意：浏览器只在 **https** 或 **localhost** 下才允许调用摄像头，
> 所以本地测试扫码请用 `http://127.0.0.1:...`，线上用 GitHub Pages 的 https 地址。
